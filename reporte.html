Reporte publicado en Power BI

El reporte interactivo de Power BI se publica con "Publicar en la Web" y aparece aquí. Mientras tanto, abajo está el mismo reporte calculado en el navegador con el mismo modelo.

El proyecto completo está versionado como texto en powerbi/presupuesto-vs-real/ (formato PBIP: modelo en TMDL, reporte en PBIR). Cómo se construyó y publicó: docs/how-to-pbi.md.

Filtros

Como un segmentador de Power BI: cambia el contexto de filtro de todos los visuales a la vez. Tres industrias sintéticas con historias distintas: Manufactura (positivo), Energía (neutro) y Salud (rojo, con la campaña de invierno de junio a agosto). "Todas" es el consolidado.

Parte del portafolio Control de gestión, construido como software · por Hernán Elías Sánchez · datos 100% sintéticos: ninguna cifra ni regla de un empleador.

English: The report built on centinela's Power BI semantic model, recomputed in the browser from the same synthetic data the model loads: three industries with different stories (manufacturing positive, energy neutral, healthcare red with a winter peak). Every visual can show the DAX measure behind it, read live from the TMDL file versioned in the repo, so the page and the model cannot drift apart. The interactive Power BI report itself is embedded at the top through "Publish to web" once it is published.
