Para el equipo técnico: lo que hay detrás de los reportes.

Power BI como código Modelo en TMDL y reporte en PBIR versionados en Git, con tests que validan el esquema y que cada visual use medidas que existen. Explorador con DAX en vivo El mismo reporte recalculado en el navegador; cada visual muestra la medida DAX leída desde el modelo. Motor en Python CLI sin dependencias que cruza presupuesto vs. real y clasifica desviaciones; probado con pytest. Explorador de datos Tres corridas reales del motor con el umbral de alerta ajustable en vivo.

English: A Power BI showcase by Hernán Sánchez (management control, FP&A and People Analytics). Each report includes the interactive version, downloadable synthetic data (CSV, Excel, .pbix and the PBIP project as code) and a short guide to its model and DAX measures. Behind them: a dependency-free Python engine, Power BI versioned as code (TMDL and PBIR) and tests that keep the data, the model and the pages telling the same story. Synthetic data only, never a real employer's numbers.
