centinela

Motor de seguimiento de desviación Presupuesto vs. Real por centro de costo, con alertas por umbral configurable — datos 100% sintéticos.

Motor

Un CLI en Python (sin dependencias externas) cruza un presupuesto planificado contra la ejecución real, calcula la desviación en $ y % por línea, y clasifica cada una en ok, alerta o crítica según un umbral configurable. Ninguna celda se omite: una línea presupuestada sin gasto real (o viceversa) se completa con monto 0 explícito, no desaparece de la agregación.

Este repo es parte de un portafolio más amplio de herramientas de datos — todas con el mismo compromiso: datos sintéticos o del propio visitante, nunca datos reales de un empleador.

consulta — motor OLAP embebido en el cliente: SQL sobre CSV y Parquet con DuckDB-WASM, 100% en el navegador, sin backend y sin que el archivo salga del equipo. Ver demo · repo

English: A dependency-free Python CLI that reconciles a planned budget against actual spend per cost center, computes the $ and % deviation, and classifies each line as ok / warning / critical against a configurable threshold — no cell is dropped, a budgeted line with no matching actual (or vice versa) is filled with an explicit zero rather than silently disappearing from the aggregation. The same logic is modeled in Power BI (DAX measures documented in docs/how-to-pbi.md) and published publicly above via Power BI's "Publish to Web" — synthetic data only, never a real employer's numbers.
